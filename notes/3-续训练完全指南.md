# 继续预训练（Continue Pre-Training）

## 1. 什么是继续预训练？

继续预训练是指在一个**已有预训练 checkpoint** 的基础上，使用新数据继续训练语言模型，而不是从随机初始化开始。

```
随机初始化 → [初次预训练] → checkpoint-10000 → [继续预训练] → 最终模型
```

### 与初次预训练的核心区别

| 对比项 | 初次预训练 (qwen_pt.py) | 继续预训练 (qwen_pt_continue.py) |
|--------|------------------------|----------------------------------|
| 模型起点 | 随机初始化 / 配置文件 | 已有 checkpoint |
| 学习率 | 较大（如 1e-4） | 极小（1e-8） |
| 目标 | 从零学习语言知识 | 在已有知识上补充新领域 |
| 风险 | 无 | 灾难性遗忘 |

---

## 2. 为什么需要继续预训练？

1. **补充领域知识**：初次预训练数据可能覆盖不足某些垂直领域（医疗、法律、代码等）
2. **增量更新**：有新数据时无需从头训练，节省大量算力
3. **迁移适配**：将通用模型适配到特定语言或风格

---

## 3. 灾难性遗忘（Catastrophic Forgetting）

### 问题描述
神经网络在学习新任务时，会覆盖旧任务的权重，导致旧能力下降甚至消失。

### 本脚本的应对策略

```python
learning_rate=1e-8   # 极小学习率，权重更新幅度极小
```

学习率越小，每步参数更新量越小，对原有权重的破坏越少：

```
参数更新量 = 学习率 × 梯度
1e-8 × grad  <<  1e-4 × grad
```

## 4. 代码流程详解

### 4.1 加载已有 Checkpoint

```python
MODEL_PATH = ".../checkpoint-10000"

model = AutoModelForCausalLM.from_pretrained(
    MODEL_PATH,
    torch_dtype=torch.bfloat16,
    attn_implementation="flash_attention_2"
)
tokenizer = AutoTokenizer.from_pretrained(MODEL_PATH)
```

- `MODEL_PATH` 指向上一阶段的 checkpoint 目录
- tokenizer 也从同一目录加载，保证词表一致

### 4.2 数据集准备（带缓存）

```python
tokenized_datapath = os.path.join(DATA_PATH, "tokenized_dataset")

if not os.path.isdir(tokenized_datapath):
    # 首次运行：tokenize 并保存到磁盘
    ...
    train_dataset.save_to_disk(tokenized_datapath)

# 后续运行：直接从磁盘加载，跳过 tokenize
train_dataset = Dataset.load_from_disk(tokenized_datapath)
```

**缓存机制的意义**：tokenize 大规模数据集耗时数小时，缓存后重启训练无需重复处理。

### 4.3 关键训练参数

```python
training_args = TrainingArguments(
    learning_rate=1e-8,           # 极小，防止遗忘
    warmup_ratio=0.1,             # 前 10% steps 预热
    lr_scheduler_type="cosine",   # 余弦退火
    gradient_accumulation_steps=16,  # 等效扩大 batch size
    gradient_checkpointing=True,  # 节省显存
    bf16=True,                    # BF16 混合精度
)
```

#### 学习率调度曲线

```
lr
^
|  /‾‾‾\
| /      \
|/        \________
+-------------------> steps
  预热  余弦退火
```

## 5. 梯度累积与等效 Batch Size

```python
per_device_train_batch_size=24
gradient_accumulation_steps=16
```

假设使用 N 张 GPU：

```
等效全局 batch_size = 24 × 16 × N
```

梯度累积原理：
```
step 1: 前向+反向，累积梯度（不更新参数）
step 2: 前向+反向，累积梯度（不更新参数）
...
step 16: 前向+反向，累积梯度 → 更新参数 → 清零梯度
```

效果等同于一次性用 16 倍大的 batch，但显存占用只有 1 倍。

## 6. 与 qwen_pt.py 的完整对比

```python
# qwen_pt.py（初次预训练）
MODEL_PATH = "Qwen/Qwen2.5-0.5B"   # HuggingFace Hub 原始模型
learning_rate = 1e-4                 # 正常学习率

# qwen_pt_continue.py（继续预训练）
MODEL_PATH = ".../checkpoint-10000"  # 本地已训练 checkpoint
learning_rate = 1e-8                 # 极小学习率
```

其余代码结构完全相同，体现了 HuggingFace Trainer 的复用性。

---

## 7. 最佳实践

1. **学习率选择**：继续预训练的 lr 通常为初次预训练的 1/100 ~ 1/1000
2. **数据混合**：可以混入少量原始预训练数据，进一步缓解遗忘
3. **评估指标**：训练过程中定期在原始任务上评估，监控遗忘程度
4. **Checkpoint 命名**：用 WandB run name 或目录名区分不同阶段，便于回溯
